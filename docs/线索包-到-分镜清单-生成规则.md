# 线索包 → 分镜清单 生成规则

红审通过后才生成。不添加线索包里没有的情节、表情或评论。
字段以「线索包 → 分镜清单」标准模板为准，许可门以「合法画面来源规则」为准。

## 1. 片子头

- 标题、事实钩子、简介四段（时间地点、发生了什么、各方怎么说、信源署名）只从线索包提取，不改写成预判、站队或评论。
- 事实钩子必须能作为 CUT 01 的口播，覆盖前 15 秒。

## 2. 封面

- 默认不指定素材静帧，必须写明「纯文字封面」或「图形设计封面」。快讯线默认「图形设计封面」。不要另找未过许可门的图。
- 只有调研已经提供本期过许可门的静帧时，才指定封面镜，并抄写对应 CUT、来源 URL、许可（名称 + 条款页）和精确时码。

## 3. 事实句怎么拆镜

- 一条事实句通常一镜；「各方怎么说」可按信源分镜，但不发明新说法。
- CUT 01 为开头钩子，时码须覆盖 00:00.00–00:15.00。
- 没有过许可门的实拍，一律用地图卡或数据卡，不生成虚构现场，不把库存空镜标成事发现场。
- 实拍镜的来源 URL、许可、起止时间必须来自调研已核对的条目，不得编造。
- 图形镜必须写出四段提示词；锁定元素只准使用线索包中的地名、日期、数字和称谓。

## 4. 不能自动填写的

- 不编造许可、条款页、时码或出处 URL。
- 许可门只核字段是否写全，是否属于新华社、总台或其他报道成片，仍须在做线索包和选画面时人工过。
- 缺必填项的那一镜不进渲染；不要为了过门而补假字段。
