# 线索包 → 分镜清单（标准模板）

一期一份。缺必填项不进渲染。不添加线索包里没有的情节、表情或评论。
封面、分句字幕、开头事实钩子按既有周末大修方案执行，不从成片抽封面。
许可门以「合法画面来源规则」为准。

## 0. 片子头

- 产线：时政快讯 / 军事史 / See China
- 期号 / 工作名：
- 标题（只写发生了什么）：
- 事实钩子（前 15 秒口播，只讲发生了什么，不用栏目名或预判）：
- 简介：
  - 时间地点：
  - 发生了什么：
  - 各方怎么说：
  - 信源署名：
- 线索包版本：
- 红审状态：通过 / 退回
- 预估时长：

## 1. 封面（必填，单独成栏）

封面用设计模板：主标题 + 一句事实副题；有指定静帧时再加上本集画面。禁止从成片截取，也不得从未授权报道里截图。

- 是否指定素材静帧：是 / 否
- 若不指定：封面类型必须二选一，写明「纯文字封面」或「图形设计封面」。剪辑师1不必另找静帧，也不要使用未过许可门的图。
- 若指定：必须来自本期已过许可门的那一镜，下面四项必填。
  - 对应 CUT：
  - 画面来源 URL：
  - 许可（名称 + 条款页）：
  - 精确时码（素材入点；精确到秒，能到帧更好）：
- 主标题 / 事实副题：
- 缩略图检查：16:9 下主标题可读

## 2. 分镜（每一镜一张，缺一项不进渲染）

```
CUT:
时码: 00:00.00–00:00.00
镜类: 开头钩子 / 正文 / 转场图卡 / 结尾
事实句: （发生了什么 / 各方怎么说）
出处:
画面类型: 官方实拍 | 公有领域 | 明确许可 | 地图卡 | 数据卡
来源 URL:
许可: （名称 + 条款页；自制图卡写「自制」，有底图仍须写底图许可）
起止时间: （素材入点–出点；自制图卡写「自制」）
字幕: （按句拆开，最多两行；不挡地图注记和底边 4% 安全区）
指定封面: 否 / 是（若是，须与第 1 栏的来源、许可、精确时码一致）

图形提示词: （图卡必填；纯实拍写「无」）
  总规格:
  锁定元素:
  按秒分镜:
  禁止项:

禁止: 不虚构现场；不添加线索包没有的情节或表情；不用未授权的电视、通讯社或新闻网站成片；不站队、不预测
```

### 图形提示词写法（占位示例，不可用于成片）

```
总规格：16:9，卡面或地图，信息图风格，无人物演绎
锁定元素：只使用线索包中的地名、日期、数字和称谓，与出处一致
按秒分镜：0.0–2.0 地图标出地点；2.0–5.0 数据卡出示数字及出处
禁止项：不生成冲突或灾难现场，不出现未提供的人物表情，不加预测性标题
```

## 3. 填写规则

- 图形镜：四段提示词必填。使用公有领域底图时，来源 URL 和许可仍要写；新闻地图卡默认用 Natural Earth。
- 实拍镜：来源 URL、许可（名称 + 条款页）、起止时间必填。挂在官网不等于可以二次使用；许可门过不去就改地图卡或数据卡，不得生成虚构现场。
- 快讯线：CUT 01 必须覆盖前 15 秒事实钩子；以卡面和地图为主，只在许可门通过时切入实拍；条目之间硬切。
- 字幕：按句拆条，不超两行，不挡地图注记和底边安全区。
- 封面不指定静帧时，只做纯文字或图形设计封面，剪辑师1不必另找图。
- 导演不担任新闻事实画面的主创。
